Boost.Asio

Asynchronous programming in Modern C++

High Performance • Scalable • Cross‑Platform

What is Boost.Asio?

  • Library for network & low‑level I/O
  • Asynchronous event-driven programming
  • Part of the Boost C++ Libraries
  • Forms the base for std::asio in Networking TS

Key Features

  • TCP / UDP Networking
  • Timers & Serial Ports
  • Strand-based concurrency control
  • Supports callbacks, coroutines, futures
  • Channels

Core Concept: io_context

Event processing core of Asio applications


            boost::asio::io_context io;

            io.run();  // processes all async operations

Simple Example: Hello World


#include <iostream>
#include <boost/asio.hpp>

namespace async = boost::asio;

int main() {
    async::io_context io;

    async::post(io, []() {
        std::cout << "Hello World" << std::endl;
    });

    io.run();
}

Output:

$ ./main
Hello World

Recursive Loop


void async_function(async::io_context& io) {
    static auto counter = 0;
    async::post(io, [&io]() {
        std::cout << "Hello World: " << counter << std::endl;
        ++counter;
        async_function(io);
    });
}

int main() {
    async::io_context io;
    async_function(io);
    io.run();
}

Output:

$ ./loop_example
Hello World: 0
Hello World: 1
Hello World: 2
Hello World: 3
...

Timer Loop Example


void async_function(async::steady_timer* timer) {
    static auto counter = 0;
    timer->expires_after(std::chrono::seconds(1));
    timer->async_wait([timer](const boost::system::error_code&) {
        std::cout << "Hello World: " << counter << std::endl;
        ++counter;
        async_function(timer);
    });
}

int main() {
    async::io_context io;
    async::steady_timer t(io);
    async_function(&t);
    io.run();
}

Output (1 second intervals):

$ ./timer_loop_example
Hello World: 0
Hello World: 1
Hello World: 2
Hello World: 3
...

Example: TCP Client


boost::asio::io_context io;
boost::asio::ip::tcp::socket socket(io);

socket.connect({boost::asio::ip::make_address("127.0.0.1"), 8080});
socket.write_some(boost::asio::buffer("Hello!"));

Non‑Blocking with async_read


socket.async_read_some(
    boost::asio::buffer(data),
    [](auto ec, std::size_t bytes) {
        if (!ec)
            std::cout << "Received: " << bytes << " bytes
";
    });

👉 Handler runs when operation completes

Strands: Thread Safety

Guarantees handler execution order


boost::asio::strand strand(io);

boost::asio::post(strand, [] {
    std::cout << "Executed without race conditions!";
});

Boost.Asio Execution Flow

  • 1️⃣ Setup async operation
  • 2️⃣ Provide completion handler
  • 3️⃣ Call io_context.run()
  • 4️⃣ Handler triggers on I/O completion
