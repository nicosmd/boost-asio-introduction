# Boost.Asio introduction

## Presentation

To open the presentation clone this repository and open `presentation/index.html` in the browser of your choice.

## Code Examples

This repository also contains the examples code from the presentation. It is a full setup CMake project with an
executable configured for each example. It uses conan to provide the Boost.Asio dependency. Checkout
the [official Conan docs](https://docs.conan.io/2/tutorial/consuming_packages/build_simple_cmake_project.html) to learn
how to use conan.
